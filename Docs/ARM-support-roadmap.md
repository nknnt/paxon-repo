## Paxon ARM Support Roadmap

Currently, Paxon's ARM support is exclusively limited to macOS (Apple Silicon).

We do not currently support ARM based Windows or ARM based Linux environments.

While we plan to evaluate and potentially support additional ARM environments if demand and ecosystem shifts warrant it in the future, given Paxon's current user base size and the current lack of active ARM Windows/Linux users, broader ARM support is expected to take a very long time.

See [platform differences](/Docs/platform-differences.md) for more details on current system requirements and supported architectures.
